# MINOR-PROJECT-04
SQL project covering joins, subqueries, window functions, CTEs, and data analysis using the BookMart dataset.

## BookMart SQL Project

This SQL-based data analysis project uses the fictional **BookMart** online bookstore dataset. The project focuses on working with relational data across three connected tables: **authors, books, and sales**.

The project demonstrates practical SQL concepts including **INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN, SELF JOIN, UNION, subqueries, correlated subqueries, EXISTS, NOT EXISTS, window functions, and Common Table Expressions (CTEs)**.

The analysis includes identifying relationships between authors and books, analysing sales and revenue, finding unsold books, comparing book prices, ranking books within genres, calculating running totals, analysing mentor relationships, and identifying top-performing books and genres.

### Dataset

The BookMart dataset contains:

* **10 authors**
* **25 books**
* **40 sales records**

The tables are linked through primary and foreign keys, allowing you to apply different SQL techniques for data exploration and analysis.

### Project Objective

The main objective of this project is to strengthen practical SQL skills by analysing relational bookstore data and applying advanced SQL techniques to answer business-oriented questions related to books, authors, sales, revenue, genres, and customer transactions.
